# 新手上路

MaaAutoNaruto 是一款基于[MaaFramework](https://maafw.xyz)开发的`火影忍者手游`自动化工具。

## 快速开始

> [!TIP]
> 已经购买了 [mirror 酱](https://mirrorchyan.com/zh/get-start)服务？试试[高速下载](https://mirrorchyan.com/zh/projects?rid=MaaAutoNaruto&os=windows&arch=x64&channel=stable)！

1. 在[release页面](https://github.com/duorua/narutomobile/releases/latest)下载最新版本。

2. 将压缩文件内的所有内容都解压到单独的文件夹。

3. 在模拟器设置里将调整为平板**1920×1080**并**锁定屏幕旋转**为横屏以达到最佳运行效果。

4. 运行`MFAAvalonia.exe`，学习软件入门指引教程。

5. 调整软件配置，然后点击`开始任务`。

> [!TIP]
> 日常配置、模拟器注意事项、安卓实机限制和自定义键位请阅读[使用说明](./manual.md)。如果遇到问题，请再仔细阅读[常见问题解决方案](./faq)。
