# 使用说明

本页汇总日常使用中的环境要求、注意事项和常用配置方法。遇到无法解决的问题时，请先查看[常见问题](./faq.md)。

## 手册与资料

- [常见问题](https://naruto.natsuu.top/guide/faq.html)
- [M9A 新手上路](https://1999.fan/zh_cn/manual/newbie.html)

> [!IMPORTANT]
> 第一次使用前建议先阅读 M9A 新手上路。MaaAutoNaruto 与 M9A 的项目结构和使用框架相近，该手册可以帮你理解 MFA 的基本操作。

## 模拟器设置

1. 将模拟器分辨率设置为平板版 16:9 比例，例如 `1280×720`、`1600×900` 或 `1920×1080`。
2. 性能充足时优先使用 `1920×1080`，可以减少部分社交功能识别异常。
3. 不建议使用雷电模拟器；该模拟器可能出现随机点击问题。
4. 关闭模拟器的后台保活和网络桥接功能。部分模拟器更新后可能自动重新开启，更新后请重新检查。

## 游戏内注意事项

1. 使用 MAN 不需要开通游戏或 QQ 会员。如果运行过程中打开了相关界面，可能是模拟器、游戏或 MAN 的识别问题。
2. 尽量不要使用会遮挡主页功能入口的忍者站街特效，例如 `带土[十尾人柱力]`、`黑土[博人传]`。
3. 部分功能不支持周年庆等主界面特效较多的主题。
4. 如果任务不是从主页功能模块进入，通常受上述特效影响较小。
5. 连点器默认键位对应火影训练场默认键位，与模拟器按键映射无关；如需修改，请参考下方的[自定义键位](#自定义键位)。

## MFA 使用建议

1. 不必过度关注实时视图的画面表现；只要任务正常运行即可。必要时可以在设置中关闭实时视图。
2. 任务旁的齿轮表示该任务有选项或描述，请根据自己需求调整。
3. 选项旁的问号支持悬停查看说明，可以帮助理解选项作用。
4. 如需迁移配置，可以把旧的 `config` 文件夹复制到新的 MAN 目录。框架更新或任务变化后不保证完全兼容。

## MAN 使用注意事项

1. 部分任务难以适配所有设备和社交媒体版本，例如分享类任务，可能需要手动调整选项。
2. 如果出现闪退，可能是由竖屏界面引起。请参考任务描述关闭相关选项，或让唤起的界面保持横屏。
3. 小游戏任务可以切换到不同的小游戏执行。

## 安卓实机注意事项

1. 早期开发主要面向模拟器，因此部分功能在手机上可能不可用，例如火影自动登录、切换账号和部分分享逻辑。
2. 安卓实机通常需要了解 Shizuku 的使用方法，或者已获得 root 权限。
3. 低版本 Android 可能不支持后台模式，可以尝试使用前台模式。

## MFA 常用功能

1. 第一次启动会有入门教程；公告和教程之后可以在 `设置 -> 关于我们` 中重新唤起或导出。
2. 右键任务可以单独运行该任务，或运行该任务及后续任务。
3. 可以重置任务、添加任务，并配合定时、通知等功能形成自己的配置。
4. 可以创建多个配置来运行不同任务流；也可以尝试用这种方式多开。
5. 可以复制 `config` 文件夹到新的 MAN 目录以保留设置，但不保证在新版本中继续兼容。

## 无人值守自动化

需要长时间无人值守、定时启动或自动运行时，可以使用 [AUTO-MAS](https://doc.auto-mas.top) 的 [MFA 专项](https://doc.auto-mas.top/docs/script-guide/maafw.html)。

## 自定义键位

自定义键位依赖 MAN 根目录下的这些文件：

- `自定义键位.bat`
- `Custom_Keybindings.json`
- `default_Keybindings.json`

> [!WARNING]
> 如果不了解 MaaFramework 的键位机制，建议使用 MfaToolPlus 等专用截图工具修改，不要直接猜测 JSON 内容。

推荐流程：

1. 使用专用截图工具截取自己的键位区域。
2. 替换 `Custom_Keybindings.json` 中对应按键的范围。
3. 启动 `自定义键位.bat`，选择“更换键位”或“更换默认键位”。

截图得到的按键范围最好略小于实际键位。范围太大时，随机点击可能命中按键边缘，导致误触。
